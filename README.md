# musical-octo-guacamole

## Preview locally

```sh
python3 -m http.server 8000 --directory site
```

Open http://localhost:8000. Run `bash scripts/check-site.sh` before opening a pull request. GitHub Pages publishes changes to `main` after **Check site** passes.
